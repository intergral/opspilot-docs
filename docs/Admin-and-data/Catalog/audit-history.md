# Audit history

Every catalog audit is recorded, so you can see what OpsPilot changed and what it cost. Open it from the [Catalog Overview](catalog-overview.md) - the **Recent audit activity** panel's **Full history** link, or the **Audit history** link under **Catalog quality**.

The history lists every audit run this billing period - what each one audited or updated, when it ran, and its **OpsPilot AI Token** cost. Expand an entry for the detail of that audit.

Your first catalog creation is covered by OpsPilot and does not use your allowance; audits you trigger afterwards use your [AI Token allowance](../../Data-insights/Features/OpsPilot/Coworker/usage.md#ai-token-allowance). See [Adding a catalog entry](entries.md#adding-a-catalog-entry) for running one.
