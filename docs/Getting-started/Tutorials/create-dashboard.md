# Create a dashboard

Custom dashboards curate the datasets you care about into a single, cohesive view - whether you are monitoring infrastructure health or debugging a specific microservice.

!!! note
    Custom dashboard creation is available on **all** OpsPilot plans.

## Before you start

- **Permissions** - make sure your profile can create and edit dashboards.
- **Query knowledge** - the query language of your data source: PromQL for metrics, LogQL for logs, or TraceQL for traces.

## Where to go next

The full dashboards documentation walks through each step:

- **[Create a dashboard](../../Data-insights/Features/Dashboards/create-dashboard.md)** - add a new dashboard and your first panel.
- **[Configure panels](../../Data-insights/Features/Dashboards/configure-panels.md)** - edit panels, set visualizations, and add thresholds.
- **[Build queries](../../Data-insights/Features/Dashboards/build-queries.md)** - query your metrics, logs, and traces.
- **[Add variables](../../Data-insights/Features/Dashboards/add-variables.md)** - make dashboards dynamic with variable dropdowns.
- **[Manage dashboards](../../Data-insights/Features/Dashboards/manage-dashboards.md)** - organize dashboards into folders and copy them.
- **[Import and export](../../Data-insights/Features/Dashboards/import-export.md)** - move dashboards in and out as JSON.

New to dashboards? Start with **[About Dashboards](../../Data-insights/Features/Dashboards/about-dashboards.md)** for how the dashboard list, folders, and integration dashboards work.
