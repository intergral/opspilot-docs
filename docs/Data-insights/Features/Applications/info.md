# Info

The **Info** tab shows an application's catalog information - its owner, tier, and dependencies.

Navigate to **Applications** > **Info** from the left-hand sidebar, or open the **Info** tab in [Application Details](application-details.md). Use the **Catalog / Label** toggle and the **Application** selector to choose an application.

---

## Catalog information

When the selected application has a [Catalog](../../../Admin-and-data/Catalog/catalog.md) entry, Info shows what the catalog holds for it - its **owner**, **tier**, and **dependency** information.

If the application is not yet catalogued, Info shows an empty state - *"This application has no catalog entry, so there is no owner, tier or dependency information for it"* - with an **Add to catalog** button to create one.
