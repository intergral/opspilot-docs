# Activity

**Activity** is the record of everything Coworker has done, and every situation change, over the last 30 days. Where [Situations](situations.md) show you what needs attention and [Insights](insights.md) show you what Coworker found, Activity shows you what it *did* - including the many times it decided not to involve you.

Navigate to **Coworker > Activity** to open it.

## Finding something

| Control | What it does |
|---|---|
| **Search activity** | Find an entry by its text |
| **All kinds** | Narrow the list to particular kinds. Opens a searchable list with **Select all**, covering situation lifecycle changes - **opened**, **escalated**, **de-escalated**, **resolved**, **reopened**, **merged**, **self-resolved**, **awaiting you** - alongside Coworker's own **notes** and **checkups** |
| **Summarize** | Ask Coworker to sum up the activity in view |

Entries run newest first, each showing its kind, what it concerned, a short account of what Coworker did and why, and how long ago. Where the entry relates to a situation, **Open situation** takes you straight to it.

## What the entries say

Each entry is labeled with what Coworker did:

| Label | What it means |
|---|---|
| **Checked** | Coworker ran a checkup on a situation and reported where it stands - what is still breaching, and by how much |
| **Extended** | Coworker attached further insights to an existing situation, because they turned out to be part of the same problem |
| **Noted** | Coworker recorded an observation against a situation without changing its state |
| **Silenced duplicate** | Something arrived that was already covered, so Coworker attached it to the existing situation instead of raising a new one |
| **Silent check** | Coworker investigated and concluded no new situation was needed, because what it found was already accounted for |

!!! tip "This is where the quiet work shows"
    **Silenced duplicate** and **Silent check** are Coworker deciding not to interrupt you. A triage sweep that finds four insights and recognizes them as a recurrence of something already open produces no alert, no situation and no notification - only an Activity entry explaining the decision.

    If you are ever unsure whether Coworker is doing anything, this page is the answer. See also [Why does Coworker raise so few situations?](faq.md#why-does-coworker-raise-so-few-situations)
